# The subject

## The problem
- To transmit the amplitudes of a signal, several measures are taken with an oscilloscope
- The amplitudes are a **source of information** that must be **analysed** and **coded** before the transmission
- Three classes, a decorator and a singleton:

| Element | Role |
|---|---|
| `source` | the measured amplitudes and their probabilities |
| `analyse` | the entropy and the self-information of a source |
| `codage` | inherits from `analyse`: two ways to code the amplitudes |
| `déco` | a decorator that changes `codes_binaires` |
| `single` | the singleton from which `source` inherits |

## The plan of the solution
1. Class `source`
2. Class `analyse`
3. Class `codage` (inheritance)
4. The decorator `déco`
5. The singleton `single`
6. The main program
- The order matters in the file: `single` before `source`, `déco` before `codage`

# Question 1 · source

## Question 1: statement
- Define a class `source` for the measured amplitudes
  - the constructor has an attribute `nbr` read with `input`: the **number of measures**, with values in [0, 5 V]
  - an attribute `obs`: an empty **list** for the observations
  - an attribute `dic`: an empty **dictionary**
  - an attribute `R`: the **redundancy** of the source, set to 0
- Methods:
  - `mesure`: fills `obs` with `nbr` integer values in [0, 5]
  - `probas`: counts the occurrences of each amplitude in `obs` and stores them in `dic` (keys = amplitudes, values = number of occurrences). Adds an attribute `P`: a numpy array with the probabilities (the values of `dic` divided by `nbr`). `P` contains the probabilities of the **6 amplitudes 0 to 5**
  - `Display`: displays the dictionary and the list

## Question 1: solution
```python
import math, random
import numpy as np

class source:
    def __init__(self):
        self.nbr = int(input("Number of measures: "))
        self.obs = []
        self.dic = {}
        self.R = 0

    def mesure(self):
        for i in range(self.nbr):
            self.obs.append(np.random.randint(0, 6))     # integers from 0 to 5

    def probas(self):
        for a in self.obs:
            self.dic[a] = self.dic.get(a, 0) + 1         # count each amplitude
        self.P = np.zeros(6)
        for a in range(6):
            self.P[a] = self.dic.get(a, 0) / self.nbr    # P[a] = probability of amplitude a

    def Display(self):
        print("obs =", self.obs)
        print("dic =", self.dic)
```
- `np.random.randint(0, 6)` gives 0, 1, ..., 5: the upper bound is **excluded**
- `self.dic.get(a, 0)` returns 0 when the amplitude is not in the dictionary yet

## Question 1: remarks
- `P[a]` is indexed by the **amplitude**, so `P` always has 6 values in the order 0 to 5, even if an amplitude never appeared (`dic.get(a, 0)` gives it a probability 0)
- The official solution fills `P` in the order of the keys of `dic`: the position then depends on the order of appearance, and the array breaks when an amplitude is missing
- `P` sums to 1

# Question 2 · analyse

## Question 2: statement
- To analyse the source, define a class `analyse` with:
  - an attribute `Objet`: a `source` object (given to the constructor)
  - an attribute `info`: an empty list
  - an attribute `E` (the **entropy**): 0
- Two methods:
  - `calcul`: calculates the entropy `E = − Σ p·log₂(p)` and the self-information `I = − log₂(p)` of every probability. `E` is stored in `E` and the information in `info`. Use `math.log(p, 2)`
  - `redondance`: calculates the redundancy of `Objet` and puts it in its attribute `R`: `R = 1 − (E / log₂(number of symbols))`

## Question 2: solution
```python
class analyse:
    def __init__(self, a):
        self.Objet = a                  # the source object
        self.info = []
        self.E = 0

    def calcul(self):
        for p in self.Objet.P:
            i = -math.log(p, 2) if p > 0 else 0      # self-information of p
            self.info.append(i)
            self.E += p * i                          # entropy: sum of p * I(p)

    def redondance(self):
        self.Objet.R = 1 - self.E / math.log(6, 2)   # 6 symbols (amplitudes 0 to 5)
```
- `Objet` is **another object** stored as an attribute: `self.Objet.P` is the array `P` of the source
- `E = Σ p × I(p)`: `i` is `−log₂(p)`, so `p * i` is `−p·log₂(p)`
- `redondance` writes in the attribute `R` of **`Objet`** (the source), as asked
- `p > 0`: `math.log(0)` is an error, an amplitude that never appeared has no information (and weight 0 in `E`)
- The maximum entropy of 6 symbols is `log₂(6)`, so `R` is 0 for a perfectly uniform source

# Question 3 · codage

## Question 3: statement
- Define a class `codage` that **inherits** from `analyse`
  - the constructor has a parameter (a `source` object), calls the constructor of the parent class and has an attribute `Codes`: an empty list
- `codes_binaires` (no parameter): a **Shannon coding**
  - the length of a code is the smallest integer **greater than or equal to** the self-information stored in `info`
  - `round(x)` gives the nearest integer: if it is smaller than the information, add 1
  - for each length `L`: a string `c = ""` to which we add `L` times `str(random.randint(0, 1))`, with `+`. The code is added to `Codes`
- `codes_probas(S)`: with a parameter `S` chosen by the user
  - the probabilities whose **position is smaller than `S`** get a code that starts with `0`, followed by a binary sequence of a size equal to the position of the probability in `P`
  - for the positions from `S`, the code starts with `1`

## Question 3: solution, codes_binaires
```python
class codage(analyse):
    def __init__(self, b):
        super().__init__(b)             # the constructor of analyse
        self.Codes = []

    def codes_binaires(self):
        for i in self.info:
            L = round(i)
            if L < i:                   # round went down: add 1
                L += 1
            c = ""
            for j in range(L):
                c += str(random.randint(0, 1))
            self.Codes.append(c)
```
- `super().__init__(b)` builds `Objet`, `info` and `E` before `codage` adds `Codes`
- `round(i)` may go down: then `L < i` and we add 1 to get the smallest integer greater than or equal to the information

## Question 3: solution, codes_probas
```python
    def codes_probas(self, S):
        self.Codes = []
        for i in range(6):
            c = "0" if i < S else "1"   # the first bit depends on the position
            for j in range(i):          # then i random bits
                c += str(random.randint(0, 1))
            self.Codes.append(c)
```
- `codes_probas` empties `Codes` first: the codes of the previous call are not mixed with the new ones

# Question 4 · The decorator

## Question 4: statement
- To change the behaviour of `codes_binaires`, a decorator `déco` creates a new function:
  1. it first **runs the original method**
  2. it gets the probabilities of the attribute `Objet` in a local variable `pb`
  3. it sorts `pb` in **descending** order: `pb = np.sort(pb)[::-1]`
  4. for each probability it gives a code word whose length equals its position: the first (position 0) gets **1 bit**, the next 2 bits, and so on. The bits come from `str(random.randint(0, 1))`, are accumulated in an empty string, then stored in `Codes` with `insert`
- **What modification must be applied to the method to use `déco`?**

## Question 4: solution, the decorator
```python
def déco(fonc):
    def nouveau(self):
        fonc(self)                          # 1. the original method
        pb = self.Objet.P                   # 2. the probabilities
        pb = np.sort(pb)[::-1]              # 3. sorted, biggest first
        self.Codes = []
        for i in range(len(pb)):            # 4. one code per probability
            c = ""
            for j in range(i + 1):          # position 0 -> 1 bit, position 1 -> 2 bits...
                c += str(random.randint(0, 1))
            self.Codes.insert(i, c)
    return nouveau
```
- A decorator receives a function (`fonc`) and returns a **new function** that replaces it
- `nouveau(self)` has the parameter `self`: it replaces a **method**, so it will receive the object
- The decorator is defined **before** the class `codage`: `@déco` is evaluated when the class is created

## Question 4: the answer
```python
class codage(analyse):
    ...
    @déco                               # the only change
    def codes_binaires(self):
        ...
```
- **We write `@déco` just before the function**. After that, calling `C.codes_binaires()` really calls `nouveau(C)`
- `@déco` before `def codes_binaires` is the same as writing `codes_binaires = déco(codes_binaires)` after it
- In the subject the question says `codes_probas`, but the text of the same question and the official code both decorate **`codes_binaires`**: this is the method that is modified

# Question 5 · The singleton

## Question 5: statement
- To manipulate **a single source**, transform the class `source` into a **singleton** with the **inheritance** approach
- Which changes must be applied to `source` to create the singleton `single` by inheritance?

## Question 5: solution
```python
class single:
    _instance = None
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:                       # first call: create the object
            cls._instance = super().__new__(cls)
        return cls._instance                            # every call: the same object

class source(single):                                   # the only change
    ...
```
- **We write the name of the singleton `single` in the signature of the class `source`**: `class source(single):`
- `__new__` **creates** the object (before `__init__`): the first call stores it in `_instance`, the next calls return the same one
- `a = source(); b = source()` gives the **same** object: `a is b` is `True`
- Careful: Python runs `__init__` again on that same object at every `source()` call (here it would ask `nbr` again)

# Question 6 · The main program

## Question 6: statement
- In the main program:
  - create a `source` object and call `mesure`, `probas` and `Display`
  - create the `codage` object and call `calcul`, `redondance`, `codes_binaires` and `codes_probas`
  - display the list `Codes` **after each call**

## Question 6: solution
```python
Ob = source()                 # Number of measures: 50
Ob.mesure()
Ob.probas()
Ob.Display()

C = codage(Ob)
C.calcul()
C.redondance()
C.codes_binaires()
print(C.Codes)
C.codes_probas(3)
print(C.Codes)
```
- The `source` object `Ob` is given to `codage`, which gives it to `analyse`: it becomes `C.Objet`

## An example run (50 measures, the codes are random)
```text
obs = [5, 3, 4, 0, 1, 3, 5, 0, 0, 1, 4, 5, 4, 1, 2, 4, 5, 2, 4, 3, ...]
dic = {5: 9, 3: 6, 4: 9, 0: 8, 1: 13, 2: 5}
P = [0.16 0.26 0.1  0.12 0.18 0.18]
E = 2.5182 bits        R = 0.0258
['1', '00', '001', '0100', '11010', '011010']      <- codes_binaires (with @déco)
['0', '00', '010', '1110', '11111', '101011']      <- codes_probas(3)
```
- The 6 probabilities sum to 1; the entropy is close to the maximum `log₂(6) = 2.585`, so the redundancy is small
- With `@déco`, the first list does not have the Shannon lengths any more: lengths 1, 2, ..., 6
- `codes_probas(3)`: the 3 first codes begin with `0`, the 3 last ones with `1`
